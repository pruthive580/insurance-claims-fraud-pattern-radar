The problem

Fraud hides between claims, not inside one

Same three claims, three different policyholders. Reviewed alone, each passes. Only the network reveals they all funnel through one flagged repair shop.

Architecture

Small, layered, deterministic-core — dataset-driven

Scoring is 100% reproducible — the AI reads messy claims, writes notes / referrals, and monitors the engine to suggest missed rules a human approves (🧪 Rule Lab), all on local Ollama. Swap claims.json for real data, zero code changes.

How it works

One claim → a routed, explained decision

Worked example — the walk-in claim, points accumulating to a score:

R1 +15 R12 +15 R13 +10 R8 +12 R7 +10 R6 +5 R11 +7 = 74 HIGH → SIU

The score is always the exact sum of fired-rule points — additive, reproducible, and auditable line by line.

The engine

16 rules across 6 fraud categories

Colour = category · number = points. Every rule is tested positive, negative, and at its exact boundary.

Score bands → action

The score drives a concrete routing decision

BandScoreRouting action
LOW0 – 29Straight-through / auto-adjudicate
MEDIUM30 – 59Adjuster review with reason codes
HIGH≥ 60Route to SIU queue — top of the investigator list

Straight from the #12 / #48 rule card. This one number powers both the ranked queue and the auto-routing.

The centrepiece

Fraud-ring detection via network analysis

Index every identifier; a value spanning ≥ 2 distinct claimants becomes an edge. Rings are the connected components. Same-claimant reuse is not a ring — that's the serial-claimant rule (R5). In the dashboard this renders live as an entity graph: every shared detail (📞/🔧/⚖️) is its own node, so a box wired to several claimants is the ring — you see it, you don't decode it.

Live at intake

A brand-new claim joins the ring in real time

Detection is dynamic, not precomputed — the ring genuinely re-links the moment the claim lands. In the dashboard, click ＋ Score claim at intake → 🔴 Ring member to show it live.

AI at the edges

AI wraps the engine — it never decides the verdict

Messy → structured going in, structured → readable coming out, and a human-gated way to grow the rules. The score, band and ring in the middle are never AI-decided.
